# PATCH: switched from exact pins to floor/ceiling ranges. The exact pins
# (numpy==1.26.3, pandas==2.2.0, scikit-learn==1.4.0) have no prebuilt
# wheels for Python 3.13 — pandas in particular only got cp313 wheels
# starting at 2.2.3, so pip was falling back to compiling pandas from
# source and failing. Ranges let pip's resolver pick whatever mutually
# compatible, wheel-available versions match the Python Railway actually
# builds with, instead of needing an exact version pinned in advance for
# an interpreter version outside our control.
numpy>=1.26.3,<3.0
scikit-learn>=1.4.0,<2.0
pandas>=2.2.3,<3.0
